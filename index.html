행사 내빈 및 의전 검토

행사 역할, 산업 연관성, 기관 내 직위를 함께 고려해 검토용 순서를 제안합니다.
내빈 명단 이용방법
  1. 내빈양식 다운로드 후 엑셀에서 성명·직위·소속 등 내빈 정보를 입력합니다.
  2. 엑셀에서 파일 → 다른 이름으로 저장 → CSV UTF-8(쉼표로 분리)(*.csv)를 선택합니다. 웹 페이지(.html) 형식은 선택하지 마세요.
  3. 명단불러오기로 파일을 가져온 다음 정렬/검토를 실행합니다.
  4. 완료된 명단은 PDF저장 또는 인쇄로 출력합니다.
※ 필수 열: 성명·직위·소속 / 쉼표(,) 구분 CSV 권장

참고 데이터 편집
직위·기관별 검토 후보 목록이며 공식 국가 의전서열표가 아닙니다. 같은 분류 안의 표시 순서도 법적 순위를 의미하지 않습니다. 직위는 예시이며 현직자·기관명은 행사 당일 재확인하세요.
직위 / 기관기관 유형검토 포인트 · 근거 성격
참고 경로: 국가법령정보센터 · 부산광역시 · BNK금융그룹. 출처 링크는 기관 확인 경로이며 각 행의 상대적 서열을 입증하는 자료는 아닙니다.
행사 명단과 관리자 참고 DB는 이 브라우저에 저장됩니다. 다른 PC에서는 CSV로 내보내고 불러와야 하며, 자동 동기화되지 않습니다.
